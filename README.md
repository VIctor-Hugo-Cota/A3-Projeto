# Projeto prático – Sistema de Folha de Pagamento em Java. 
O objetivo é criar um programa que permita cadastrar colaboradores e calcular o salário final de acordo com o tipo de vínculo. Cada colaborador possue um registro com:

* nome completo;
* número de registro;
* salario Base;
* tipoVinculo;

## Tipos de colaboradores:
1. Funcionário padrão;
   * Recebe apenas o salário base.

3. Funcionário comissionado;
   * salário base + comissão.( Comissão = (vendas * percentual / 100))

3. Funcionário de produção;
   * salário base + bônus por produtividade. (Bônus = (valorPorPeça * quantidadeProduzida));
